## 📖 Acerca del proyecto

**AgroFuturo Ecuador** es un sitio web informativo e interactivo desarrollado con el propósito de dar a conocer la importancia de la agricultura ecuatoriana y cómo las nuevas tecnologías pueden contribuir a mejorar este sector.

A través de diferentes secciones, la página presenta información sobre los cultivos de Ecuador, herramientas tecnológicas aplicadas al campo y actividades educativas que permiten a los visitantes aprender de una manera sencilla.

El proyecto fue desarrollado como parte de una actividad académica, aplicando conocimientos de **HTML5, CSS3 y JavaScript**, con especial atención a la organización del contenido, la experiencia del usuario y el diseño adaptable.

> 🌎 **Nuestra idea:** demostrar que la agricultura y la tecnología pueden trabajar juntas para construir un futuro más sostenible.

## 🧭 Secciones del sitio web

La página está organizada en seis secciones principales para facilitar la navegación y presentar la información de manera ordenada.

### 🏡 01. Inicio

Es la primera sección que encuentra el visitante al ingresar al sitio.

Incluye el nombre del proyecto, un mensaje de bienvenida y botones que permiten explorar los contenidos disponibles.

**Su propósito** es captar la atención del usuario y presentar la temática principal de AgroFuturo Ecuador.

### 🌎 02. Introducción

Presenta información general sobre la importancia de la agricultura en Ecuador y su relación con el desarrollo tecnológico.

Esta sección permite comprender por qué la innovación y el uso responsable de los recursos son importantes para el futuro del sector agrícola.

### 🌾 03. Cultivos

Muestra diferentes cultivos agrícolas mediante tarjetas que contienen imágenes e información.

**Funcionalidad destacada:** permite utilizar filtros para visualizar cultivos según la región seleccionada.

Esto facilita la exploración del contenido y hace que la navegación sea más interactiva.

### 🤖 04. Tecnología

Explica algunas aplicaciones de la tecnología en la agricultura, como:

- 💧 Sistemas de riego.
- 📡 Sensores para el monitoreo agrícola.
- 📊 Herramientas digitales para mejorar la gestión de los cultivos.

El objetivo es mostrar cómo estas herramientas pueden contribuir al aprovechamiento de los recursos y a la modernización del trabajo agrícola.

### 🧠 05. Aprende

Contiene un cuestionario interactivo relacionado con la información presentada en el sitio.

El usuario puede seleccionar respuestas y recibir mensajes que le permiten conocer el resultado de su elección.

Esta actividad busca reforzar el aprendizaje de una forma más dinámica.

### ✉️ 06. Participa

Incluye un formulario mediante el cual el visitante puede ingresar información en los campos correspondientes.

El formulario cuenta con validaciones realizadas mediante JavaScript para identificar campos incompletos o datos incorrectos.

**Importante:** actualmente se realiza la validación en el navegador. El envío o almacenamiento real de los datos requeriría una conexión con un servidor o servicio externo.

## 📱 Diseño responsive

AgroFuturo Ecuador utiliza un enfoque **mobile first**, es decir, se considera primero la visualización en pantallas pequeñas y posteriormente se realizan ajustes para dispositivos de mayor tamaño.

Para conseguirlo se emplean herramientas como:

- **Flexbox:** permite organizar elementos en filas o columnas.
- **CSS Grid:** facilita la distribución de tarjetas y contenidos.
- **Media queries:** permiten adaptar la presentación según el ancho de la pantalla.
- **Imágenes fluidas:** ayudan a evitar que las imágenes sobrepasen el espacio disponible.

### Dispositivos considerados

| Dispositivo | Ancho de referencia |
|---|---|
| 📱 Móvil | 375 px |
| 📲 Tableta | 768 px |
| 💻 Escritorio | 1366 px |

Estos tamaños pueden utilizarse como referencia para las pruebas y capturas del proyecto.

## 🚀 Instalación y ejecución

El proyecto no requiere instalar programas adicionales ni configurar una base de datos para visualizar sus funcionalidades actuales.

### Paso 1. Obtener los archivos

Descargar o copiar la carpeta completa de **AgroFuturo Ecuador**.

### Paso 2. Revisar la estructura

Comprobar que los archivos estén organizados correctamente:

```text
index.html
css/styles.css
js/script.js
img/
```

### Paso 3. Abrir el sitio

Abrir el archivo `index.html` en un navegador como Google Chrome, Microsoft Edge o Mozilla Firefox.

### Paso 4. Explorar las funcionalidades

Una vez abierta la página, se pueden visitar las diferentes secciones y probar:

- El menú de navegación.
- Los filtros de cultivos.
- El cuestionario interactivo.
- La validación del formulario.
- La adaptación de la página a diferentes pantallas.

**Recomendación:** utilizar Visual Studio Code para editar el código y mantener organizados los archivos.
